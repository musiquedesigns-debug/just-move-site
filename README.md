# Just Move · site

Site static, un singur fișier index.html + folderul img/.

## Publicare
Netlify: trage folderul întreg pe app.netlify.com/drop. Gata.
Cloudflare Pages / Vercel: la fel, upload folder sau repo GitHub.

## Formulare
Toate formularele trimit la Formspree. Creează un cont gratuit pe formspree.io,
ia ID-ul formularului și înlocuiește FORM_ID_AICI în index.html (apare de 5 ori).

## Poze
img/portret.jpg = portretul lui Cătălin folosit pe site. img/portret-alt.jpg = varianta a doua.
Înlocuiești orice poză păstrând numele fișierului.

## Navigare
Paginile sunt rute hash: #/copii, #/adulti, #/evenimente, #/corp, #/scoli, #/shop, #/despre, #/contact.

## Shop
Butoanele "Cumpără" nu au încă plată. Se leagă la Stripe Payment Links sau Gumroad (un link per produs).
